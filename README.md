# 💰 Telegram WebApp: Учёт долгов и кассовых чеков (Debt Tracker)

Современное мобильное приложение **Telegram WebApp** для учёта выданных и взятых долгов, расчётов, прикрепления фото чеков, автоматических отчётов и напоминаний в Telegram.

Интерфейс вдохновлён премиальным мобильным финтех-дизайном: градиентные карточки с силуэтной аналитикой, сплит-метрики «Мне должны / Я должен», плашки статусов, расписки в PDF и режим двух владельцев магазина.

---

## ✨ Основные возможности

1. **Современный мобильный UI (Fintech Style):**
   - 💳 **Главная карточка:** чистый баланс, индикаторы сальдо, силуэтная гистограмма.
   - 🟢/🟠 **Сплит-метрики:** раздельный учёт «Мне должны» и «Я должен».
   - ⚠️/🕒 **Плашки статусов:** фильтры просроченных долгов и долгов с приближающимся сроком.
   - 📊 **Прогресс выплат:** визуальный индикатор соотношения возвращённой суммы к общей сумме долга.
   - 📱 **Нижняя навигация:** вкладки «Долги», «Контакты», быстрая кнопка «+», «Аналитика», «Ещё».

2. **Работа с чеками и расписками:**
   - 🧾 Прикрепление фото чека к записи (камера / галерея / вставка).
   - 🔍 Просмотр чека в полноэкранном режиме (Lightbox).
   - 📄 **Генерация PDF-расписки:** официальный документ с реквизитами, подписями и датами для отправки должнику в Telegram.
   - 📑 **Сводный PDF-отчёт:** финансовая ведомость по всем текущим операциям.

3. **Режим безопасности «2 Владельца магазина»:**
   - Строгий белый список из 2 доверенных Telegram ID.
   - Посторонние пользователи блокируются экраном доступа и не могут получить данные.
   - Подделка ID невозможна: Telegram API криптографически заверяет данные через `msg.from.id` и `Telegram.WebApp.initData`.

4. **Интеграция с Telegram Bot:**
   - Команды бота: `/report`, `/stats`, `/daily`, `/weekly`, `/stop`, `/owners`.
   - Автоматическая рассылка ежедневных и еженедельных сводок.
   - Выгрузка базы данных в формат Excel (.csv).
   - Поддержка регулярных/повторяющихся платежей (аренда, подписки).

## 🚀 Быстрый старт и локальный запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Настройка переменных окружения
Скопируйте файл `.env.example` в `.env`:
```bash
cp .env.example .env
```
Укажите:
- `TELEGRAM_BOT_TOKEN` — токен вашего бота от `@BotFather`
- `APP_URL` — ссылка на ваше запущенное приложение (например, URL на Cloud Run или ngrok)

### 3. Запуск сервера разработки
```bash
npm run dev
```
Сервер запустится на `http://localhost:3000`.

## 🤖 Подключение к Telegram Bot

1. Откройте `@BotFather` в Telegram.
2. Создайте бота через команду `/newbot` или выберите существующего.
3. Введите команду `/newapp` или `/editapp`, чтобы привязать WebApp:
   - Укажите короткое имя приложения.
   - Вставьте URL вашего приложения: `https://<YOUR-APP-URL>`.
4. Для создания кнопки в меню бота:
   - В `@BotFather` выберите `/setmenubutton` -> выберите вашего бота -> укажите URL приложения.
